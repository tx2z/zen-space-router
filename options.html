Space Router Settings

In the picker, press R (or S for all subdomains) and then choose a space; the rule is saved with your choice.

About

Built with AI. Zen Space Router was made by tx2z with substantial help from Claude (Anthropic). It was reviewed and tested by a human in a real Zen Browser, but if you are not comfortable using AI-assisted software, please do not use it.

This is a small open-source project for the Zen community. Bug reports, feature requests, pull requests and ideas are welcome on GitHub.

Zen's native Space Routing

Recent Zen Browser versions ship their own Space Routing (Settings → Spaces). It moves tabs to a space silently, without asking, and may move the tab before this extension is consulted.

To avoid a tab being routed twice, do not create native routes for domains that have a rule here, and keep Zen's "Default route for external links" on "Most recent Space". This extension cannot read or write Zen's native routes.
