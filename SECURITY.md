# Security Policy

## Reporting a vulnerability

Please report security issues privately using GitHub's "Report a
vulnerability" feature (the Security tab on this repository), rather than
opening a public issue.

## Scope

Zen Space Router requests `<all_urls>` and `webRequestBlocking` to intercept
and cancel incoming external navigations. Reports about how these
permissions are used (or misused) are in scope; reports about Zen Browser
or Firefox itself are not.

## Response expectations

This is a personal project maintained on a best-effort basis. There is no
guaranteed response time.
